- 데이터 품질과 거버넌스를 중요하게 생각하는 엔지니어

담당할 업무
· Cloud Data Platform Engineering
  - Kubernetes 기반 데이터 플랫폼 아키텍처 설계 및 구현
  - Apache Spark, Flink 클러스터 구축 및 성능 최적화
  - 멀티 테넌트 환경에서의 리소스 격리 및 모니터링 시스템 구축
  - Terraform, Helm을 활용한 Infrastructure as Code 관리

· Real-time Data Pipeline
  - Kafka 기반 실시간 데이터 스트리밍 파이프라인 설계
  - Schema Registry, Kafka Connect를 활용한 데이터 통합
  - Flink SQL, Spark Structured Streaming을 통한 실시간 데이터 처리
  - 이벤트 기반 아키텍처(EDA) 설계 및 구현

· Data Lake & Lakehouse Architecture
  - Apache Iceberg, Delta Lake 기반 레이크하우스 구축
  - S3 호환 오브젝트 스토리지 최적화
  - Parquet, ORC 등 컬럼형 포맷 성능 튜닝
  - 파티셔닝 전략 및 데이터 라이프사이클 관리

· Observability & Data Quality
  - Prometheus, Grafana 기반 데이터 파이프라인 모니터링
  - Great Expectations, Soda를 활용한 데이터 품질 검증
  - 데이터 리니지 추적 및 메타데이터 관리
